
Return both:


# ANOMALY THRESHOLDS

Implement:

```text
discrepancy < 10%       normal
10–19.9%                low anomaly
20–34.9%                moderate anomaly
35–49.9%                serious anomaly
>= 50%                  severe anomaly
```

Any discrepancy >= 20% must generate an anomaly event.

The monitoring API should return:

```json
{
  "discrepancy": 52.3,
  "anomalyDetected": true,
  "attendanceRisk": 35,
  "riskScore": 81,
  "riskLevel": "CRITICAL"
}
```
